# 行业扩展模板与使用场景

> **日期**：2026-09-12  
> **来源**：`ZL.Gear.Docs/139`、`141`  
> **用途**：IndustryKit 使用方法、行业 Handler 开发规范、产线安全规则、验证闭环。

---

## 一、IndustryKit 定位

`ZL.Gear.Extension.Seat`（现位于 **`Gear.All/ZL.Gear.Exts`** 私有仓）是早期座椅方案：私有 `libs`、现场 Tag 硬编码。新人**不得**拷贝 Seat；应复制 **本 Kit**（`demos/IndustryKit/`，公开 MIT 模板）扩展 PCBA / 电池 / 线束等行业。

需要一个 **可复制、可验证、对齐最新 L-DSL/L-Test/L-Adapter** 的第二宿主模板。

---

## 二、决策

| # | 决策 |
|---|------|
| D1 | 新样例放在 `demos/IndustryKit/`，**不**复活 Seat 私有依赖路径。 |
| D2 | 行业特异命令走 `IGearExtension` + `RegisterHandlerWithAction`；配方走 DynamicFlow 新方言。 |
| D3 | 宿主用 `SequenceExecutorBuilder.WithExtension` + 显式 `BuiltInModules`（Demo 用 `Core`）+ **显式宿主声明 `AsLogicOnlyDemoHost()`**（docs/145）。 |
| D4 | 客户端必须提供 `verify`：含故意 FAIL 与超时契约，输出 `INDUSTRY_KIT_VERIFY_PASS`。 |
| D5 | 换行业优先 **JSON 分叉**；确需新动作再复制 Extension 工程改前缀。 |

---

## 三、明确不做

- 不把 Seat `PlcDevice` 迁进样例。
- 不把本 Kit 并入 ModuleLoader 默认列表。
- 不抽 Workflow NuGet（138）。
- 不用 SeatDemo 式代码拼步骤树作为推荐路径。

## 五、专家审查要点

| 项 | 裁决 | 依据 |
|----|------|------|
| 扩展只引 Core | ✓ 安全 | 不绑 Seat 私有 libs；ADR 138 L-Adapter |
| RegisterHandlerWithAction 双面注册 | ✓ 必修 | 仅 Handler 则 DynamicFlow ActionKey 不可用 |
| SetShared 写流程变量 | ✓ 必修 | 节点子作用域；docs/136 |
| ApplyRecipe 缺参静默默认 | ✗ 已修 | 改为 RecipeId/LimitOhm/SimulatedOhm 缺参即 Failed |
| EvaluateResult:false | ✓ 可接受 | 跳过步骤级 ExpectedResults；DynamicFlow 内 Assert 仍 Fail 步骤 |
| BuiltInModules.Core | ✓ 刻意 | 样例不被 Sensing/PLC 污染；产线按需 \| Sensing |
| verify 含 FAIL+超时 | ✓ 必修 | 防「全绿假通过」 |
| 启动期扩展注册自检 | ✓ 已加 | Client EnsureStationExtensionRegistered |
| Handler 参数样板过多 | ✓ 已加 | Core `StepArgsReader` + `StepArgSource`（ArgsOnly / ArgsThenVariables / All） |

### 5.1 Handler 参数读取（StepArgsReader）

`StepHandlerCommandAttribute.ParameterSchema` **目前仅文档/冲突校验**，不会自动绑定（docs/121 明示）。
行业 Handler 请用 **`ZL.Gear.Core.Models.StepArgsReader`**：

| 来源 | 用途 |
|------|------|
| `ArgsOnly` | 限值/配方等 fail-closed 必填（禁止从 Variables 静默兜底） |
| `ArgsThenVariables` | 本步可覆盖，否则读前序 SetShared |
| `All` | 等同 `context.Get`（Args → Variables → Global） |

示例见 `ApplyRecipeHandler` / `ProbeChannelHandler`。

### 5.2 PR 自检（复制到新 Handler / 新场景 PR）

- [ ] 限值/RecipeId：`ArgsOnly` + `TryRequire*`（**禁止** `All` / `context.Get`）
- [ ] 写流程：`args.SetShared`（**禁止** `context.Variables.Set`）
- [ ] 读前序：`GetFlowString` / `VariablesOnly`
- [ ] 可选 Args：键存在则 fail-closed（见 `ProbeChannelHandler`）
- [ ] 判据在 JSON `Assert`；L1 `Check` **单条件**（禁止 `&&`）
- [ ] verify 含故意 FAIL + 超时（`VerificationCatalog` 四用例语义不可删）
- [ ] 勿在 `WorkflowDefinition.Variables` 预置 LimitOhm 等判据

**明确不是灾难、但勿误解**

- 本 Kit **不**证明产线 PLC/真实仪表路径；ProbeChannel 为仿真，接表只改 Handler 实现。
- **不**替代 ConsoleApp 主场景库；Industry_PCBA_* 等仍在 ConsoleApp。
- Seat 工程仍保留作私有 PLC 遗产，**禁止**作为新行业拷贝源。

## 六、使用场景

| 场景 | 说明 |
|------|------|
| 教学模板 | 无硬件、无 Drivers 的 LogicOnly 行业扩展示范 |
| 行业扩展 | 复制 IndustryKit，实现 `IGearExtension`，`RegisterHandlerWithAction` |
| 配方开发 | DynamicFlow JSON（docs/134–137 新方言）；宿主 `WithExtension(...).WithBuiltInModules(...)` |
| 验证闭环 | 用 samples/IndustryKit 客户端 `verify` 做 PASS/故意 FAIL/超时闭环 |

---

## 七、产线安全规则

**禁止方向（按错即产线灾难，勿立项）**：

- ParameterSchema **自动运行时绑定**（docs/121 已否决；Schema=文档 + StepArgsReader 手写）
- 产线限值用 `context.Get` / `StepArgSource.All`
- 行业 Handler 用 `Variables.Set`（须 `args.SetShared`）
- verify **只跑 HappyPath**（须含故意 FAIL + 超时）
- Assert L1 `Check` 写 `&&`（须拆成多条单条件 Assert）

**已验证模板**：`demos/IndustryKit/`

**合规单测**：`IndustryKitHandlerComplianceTests` 扫描模板三 Handler，禁止 `Variables.Set` / `context.Get` / 限值 `All`。
